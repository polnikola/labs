# Лабораторные работы по Description.docx

Два независимых комплекта группы 2:

| Папка | № по списку | ПК | ЛР1 | ЛР2 | N для ЛР3–4 |
|---|---:|---:|---|---|---:|
| n10_pc10 | 10 | 10 | Райс | треугольная КФ | 12 |
| n3_pc3 | 3 | 3 | показательное | осциллирующая гауссовская КФ | 5 |

В каждой папке lab1.ipynb … lab4.ipynb. Все ячейки выполнены, графики сохранены. Ноутбуки самодостаточны; исходные template_*.py не нужны. Для второго комплекта принято ПК=3, как и номер по списку.

Установка: `python3 -m venv .venv`, затем `.venv/bin/pip install -r requirements.txt`.
Открытие: `.venv/bin/jupyter notebook`.

Варианты таблиц выбираются по кругу. В ЛР3–4 N=ПК+группа, независимо от номера по списку. СКО ЛР2 принято 2, порядок прототипов фильтров — 4, подавление Чебышёва II — 40 дБ. В ЛР4 ПК10 длительность ЛЧМ принята 40 мкс вместо 12 нс из ЛР3, чтобы обеспечить разрешение частотной перестройки. Допущения описаны в ноутбуках.

`scripts/build_labs.py` воспроизводит исходные ноутбуки (без выполнения ячеек). В готовых файлах выполнение уже сохранено.
